# DLSS 5 Neural Rendering 1.2.5

## Changes

- Added a **Processing Resolution** dropdown: Source, 2160p, 1440p, 1080p, and 720p. Default: 1080p. Frames resize on the GPU before processing, retain their aspect ratio, and display at the original source size. Smaller inputs are not enlarged for processing.
- Fixed Smooth mode's readiness check blocking behind the inference worker's mutex.
- Fixed frame-rate limiting that could turn a 30 FPS setting into roughly 15 FPS under small timing variations. Limits now also apply in Low latency mode.
- Reuse completed output when OBS renders the filter more than once in a video tick.
- Keep only the newest pending frame, preserve pending history resets, and discard stale output when changing resolution or processing mode.
- Added actual **enhanced FPS**, processing dimensions, active path, and last processing time to Status and periodic OBS logs.
- Corrected the Smooth mode description: latency depends on processing time; it is not guaranteed to be one frame.
- Windows-only build/release pipeline with automated cadence/resolution regression tests. The only uploaded release asset is the Windows x64 ZIP, including these patch notes.

## Suggested settings

- Start with **Smooth + 1080p + Temporal off**.
- For Temporal Mode, try **Smooth + 720p** if 1080p cannot reach your target enhanced FPS.
- Use **Match source** or an explicit NR frame-rate limit. OBS output FPS and enhanced FPS are different measurements.
- Existing Processing Mode and Temporal settings are retained. Select the suggested settings yourself when upgrading an existing filter.

## Validation

Tested with the real OBS/D3D11 renderer and DLSS NR runtime on an RTX 5090 using an animated 3840x2160 synthetic source, 30 FPS output, five seconds of warm-up, and a ten-second measurement:

| Processing settings | Enhanced FPS | Missed OBS render frames |
| --- | ---: | ---: |
| Smooth, 1080p, Temporal off | 30.0 | 0 |
| Smooth, 1080p, Temporal on | 20.9 | 0 |
| Smooth, 720p, Temporal on | 30.0 | 0 |

All five resolution options and switching between Smooth and Low latency passed the GPU smoke test. Automated tests cover jitter, rate changes, pauses, downsampling, aspect ratio, and smaller sources. These are synthetic-source results on one GPU, not a performance guarantee for every source or GPU.

## Compatibility and installation

One generic **Windows x64** package serves the runtime-supported NVIDIA RTX 20/30/40/50 series. There are no 5090-only compilation flags or GPU-generation restrictions in this build. This release was hardware-tested on an RTX 5090; other RTX generations retain runtime-dependent support and were not individually tested.

Extract the ZIP into `C:\ProgramData\obs-studio\plugins\` and restart OBS. You must supply `nvngx_dlssnr.dll` yourself at `%APPDATA%\obs-studio\plugin_config\obs-dlss5-nr\runtime\nvngx_dlssnr.dll`. The ZIP contains the plugin and the project's caller shim (`nvngx.dll_obs.dll`), not NVIDIA's proprietary runtime.

The stable path still uses CPU staging. Experimental GPU sharing remains disabled by default and is only used in Low latency mode; its known 4K instability has not been resolved by this release. Temporal Mode currently uses the CPU-staged path.
